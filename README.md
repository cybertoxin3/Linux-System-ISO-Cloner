# Universal Linux Live ISO Creator

## Create a bootable ISO image from your installed Linux system with a graphical interface.

Universal Linux Live ISO Creator is an open-source Python application
that allows users to generate a bootable Live ISO from their currently
installed Linux system.

Unlike traditional remastering tools, the application automatically
prepares the environment, installs missing dependencies, detects the
Linux distribution, and provides a multilingual graphical interface.

It is designed for users who want to:

-   Create a backup of their operating system
-   Clone their customized Linux installation
-   Generate a portable Live ISO
-   Deploy identical systems to multiple computers



## Features

-   Graphical User Interface (Tkinter)
-   Automatic Linux distribution detection
-   Automatic dependency installation
-   Automatic Penguins-Eggs installation
-   Multilingual interface (15+ languages)
-   Progress tracking
-   Parrot OS compatibility mode

## Installation

``` bash
git clone https://github.com/cybertoxin3/Linux-System-ISO-Cloner.git

cd Universal-Linux-Live-ISO-Creator

python3 iso_creator.py
```
